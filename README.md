# ⚡ برو ستور - منصة بيع واشتراكات الحسابات الرقمية (PRO Subscriptions)

منصة ويب متكاملة، خفيفة، وسريعة جداً لإدارة وبيع اشتراكات الذكاء الاصطناعي والتصميم (Google Gemini, Adobe Creative Cloud, ChatGPT Plus, Canva Pro) بنظام الدفع المحلي (فودافون كاش، محافظ كاش، وإنستاباي Instapay) مع تفعيل يدوي ولوحة تحكم مخصصة للمديرين.

---

## 🌟 مميزات المنصة

### 1. واجهة العميل (الموقع الرئيسي):
- **تصميم عصري وفخم (Dark Mode Glassmorphism):** ألوان متناسقة، خط عربي احترافي (Cairo)، ودعم كامل للشاشات والموبايل.
- **عرض الباقات:** كروت لكل اشتراك مع السعر الأصلي، السعر بعد الخصم، ومميزات الباقة.
- **طرق الدفع بضغطة زر:** كروت مخصصة لمحفظة كاش وإنستاباي مع زر **"نسخ الرقم بضغطة زر"**.
- **نموذج إرسال الطلب:**
  - اختيار الباقة.
  - الاسم (اختياري).
  - رقم واتساب (إجباري).
  - بريد Gmail (إجباري).
  - الرقم أو الحساب المحول منه (إجباري).
  - رفع ومعاينة صورة التحويل (إجباري).
- **إرسال مباشر للواتساب بعد الطلب:** زر فوري لفتح محادثة واتساب مع الدعم الفني بكود وبيانات الطلب لتسريع التفعيل.
- **متابعة حالة الطلب:** يستطيع العميل إدخال رقم هاتفه أو كود الطلب لمعرفة حالته فوراً *(قيد المراجعة ⏳ / تم التفعيل بنجاح ✅ / مشكلة بالتحويل ⚠️)*.
- **زر واتساب عائم للدعم الفني على مدار الساعة.**

### 2. لوحة تحكم الإدارة (Admin Dashboard):
- **حسابات الأدمن الاستاتيك:**
  - **الأدمن 1:** البريد: `admin1@pro.com` | كلمة السر: `admin1234@password`
  - **الأدمن 2:** البريد: `admin2@pro.com` | كلمة السر: `admin5678@password`
- **جدول الطلبات الجديدة (قيد الانتظار):**
  - كود الطلب، اسم العميل، رقم الواتساب (مع زر مباشر للدردشة)، البريد الإلكتروني، مصغّر لصورة الإيصال (يمكن الضغط عليه لعرض الإيصال بحجم كامل)، الرقم المحول منه، الباقة، والسعر.
  - زر **"تفعيل الحساب ✅"**: بمجرد الضغط عليه، ينتقل الطلب مباشرة لجدول الطلبات المفعلة.
  - زر **"مشكلة ⚠️"**: لكتابة سبب عدم استلام المبلغ للتواصل مع العميل.
- **جدول الطلبات المفعلة:**
  - يعرض نفس بيانات الطلب مع إضافة **تاريخ ووقت التفعيل** و **اسم الأدمن الذي قام بالتفعيل**.
- **إدارة الباقات (Packages Management):**
  - إضافة باقة جديدة (الاسم، التصنيف، السعر قبل الخصم، السعر بعد الخصم، الوصف، المميزات، وصورة الباقة).
  - حفظ وتحديد اسم الأدمن الذي أضاف الباقة (ولا يظهر للزبون في الواجهة الرئيسية).
  - حذف الباقات في أي وقت.
- **إعدادات الدفع والموقع:**
  - إمكانية تعديل رقم فودافون كاش، حساب إنستاباي، ورقم دعم الواتساب مباشرة من لوحة التحكم دون تعديل الكود.

## ☁️ خطوات الرفع على استضافة مجانية (Render / Koyeb)

تم تصميم هذا المشروع بحيث يكون **خفيفاً وبدون أطر عمل ثقيلة**، مما يجعله جاهزاً للرفع على أي استضافة مجانية تدعم Node.js مثل **Render.com**:

1. أنشئ حساب مجاني على موقع [Render.com](https://render.com) أو [GitHub](https://github.com).
2. ارفع كود المشروع إلى مستودع (Repository) على GitHub.
3. في Render، اختر **New +** ثم **Web Service** واربط المستودع:
   - **Build Command:** `npm install`
   - **Start Command:** `npm start`
   - **Node Version:** 18 أو 20 أو 22 أو 24.
4. اضغط **Deploy Web Service** ومبروك! ستحصل على رابط مجاني دائم (مثل `https://your-store.onrender.com`).
